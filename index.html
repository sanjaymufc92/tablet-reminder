Cross-device sync

Connect a free Firebase Realtime Database so this data updates on both your devices automatically, in real time.

  1. Go to console.firebase.google.com and create a free project (any name is fine)
  2. In the left menu, open Build → Realtime Database → click "Create Database" → start in test mode
  3. Go to Project settings (gear icon) → scroll to "Your apps" → click the web icon </> to register a web app
  4. Copy the whole firebaseConfig object it shows you, and paste it below

Paste this same config into the app on your other device (one time) to link them together. Both devices will then update live whenever either one changes something.
